# Legacy Buffer Components [DEPRECATED]

Many of these components are still used across Buffer and its products, however they are all deprecated/unmaintained. Please use Popcorn for the latest and greatest components.

These components should not be used in anything new. But if you do have to modify a component for any reason, then please add a test while you're here. The previous tests were removed when this package was migrated to buffer-mono since they were very, very old. There is currently set up for component-level testing, But configuration could be borrowed from other repos inside of buffer-mono.
